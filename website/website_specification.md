# re.inform website specification

## Overview
This document outlines the requirements for the re.inform website, a platform aimed at countering extremism through personality-based counter-narratives. The website will serve as both an information hub and a community gathering point for our initial MVP.

## Site Structure

### 1. Homepage
- **Hero Section**
  - Brief, compelling project description (1-2 sentences)
  - Primary CTA button: "Join Our Community"
  - Secondary CTA: "Learn More"
- **Problem Statement Section**
  - Short description of the issues we're addressing
  - Visual representation of the rising extremism problem (graph/illustration)
- **Solution Overview**
  - Brief explanation of our approach (personality categorization + counter-narratives)
  - Simple visualization of our methodology
- **Featured Resources**
  - 3-4 highlighted reference materials
- **Testimonials/Quotes**
  - From researchers or experts (can be added later)
- **Call to Action**
  - Discord join button
  - Feedback submission link

### 2. Manifesto Page
- **Our Vision**
  - Detailed explanation of the project's purpose
- **Our Values**
  - Key principles guiding our work
- **Our Approach**
  - Detailed methodology description
  - Explanation of personality categorization approach
- **Expected Impact**
  - How we envision the tools being used

### 3. Resources Page
- **Filterable Resource Library**
  - Categories: Books, Articles, Projects, Tools, Research Papers
  - Each resource should have:
    - Title
    - Brief description
    - Link/reference
    - Relevance tag (e.g., "Personality Types", "Counter-Narratives", "Online Extremism")
- **Recommended Reading Paths**
  - Suggested sequences for different user types

### 4. Contribute Page
- **Ways to Contribute**
  - Research contributions
  - Development help
  - Content creation
  - Testing and feedback
- **Current Needs**
  - Specific areas where help is needed
- **Contact Form**
  - For people who want to contribute in specific ways

### 5. About Page
- **Project Background**
- **Team Information** (if applicable)
- **Methodology Details**
- **FAQ Section**

### 6. Feedback Page
- **Structured Feedback Form**
  - User type selection
  - Experience questions
  - Suggestions field
  - Contact information (optional)
- **Previous Feedback Highlights** (can be added later)

## Navigation

- **Main Menu**
  - Home
  - Manifesto
  - Resources
  - Contribute
  - About
  - Feedback
- **Persistent Elements**
  - Discord community button (top right)
  - Feedback button (bottom right, floating)

## Design Elements

### Style
- **Color Scheme**
  - Primary: A calm, trustworthy blue (#3A5D9C suggested)
  - Secondary: Warmer, bridge-building orange/amber (#FF9E2C suggested)
  - Neutral backgrounds: Clean whites and light grays
  - Avoid: Red/black combinations that might feel aggressive
- **Typography**
  - Headers: Clear, authoritative sans-serif (Montserrat suggested)
  - Body text: Highly readable serif for academic feel (Merrifield or PT Serif suggested)
- **Imagery**
  - Metaphors of bridges, connections, dialogue
  - Diverse representation in any people imagery
  - Data visualizations where appropriate
  - Avoid imagery that could be politically charged

### User Experience
- **Accessibility**
  - WCAG 2.1 AA compliance
  - Readable text (min 16px body text)
  - Sufficient contrast ratios
- **Responsive Design**
  - Mobile-friendly layout
  - Simplified navigation on smaller screens
- **Load Time**
  - Optimize for quick loading (<3s)
  - Progressive image loading

## Technical Considerations
- **Frontend**
  - HTML5, CSS3, JavaScript
  - Consider lightweight frameworks (initial site could be static)
- **Backend Requirements**
  - Form submission handling
  - Resource database (could be JSON-based initially)
- **Analytics**
  - Basic visitor tracking
  - Resource popularity metrics
  - Form submission analytics

## Phase 1 MVP Priorities
1. Homepage with clear project explanation
2. Manifesto page with full project details
3. Basic Resources page with initial reference materials
4. Discord community link functionality
5. Feedback submission form
6. Mobile responsiveness

## Future Phases (post-MVP)
- Interactive personality type explorer
- Chatbot integration for counter-narrative assistance
- User accounts for personalized resources
- Community forum beyond Discord

## Timeline Considerations
- Focus on launching the informational aspects first
- Tool development can follow once community is established
- Allow for iterative improvements based on user feedback

## Content Requirements
- All copy should be approachable yet academically sound
- Avoid politically charged language that could alienate potential users
- Focus on bridge-building terminology rather than combative framing
- Ensure all claims are backed by research where possible
